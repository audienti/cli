# @audienti/cli (`audienti` / `tofu`)

Official CLI for Audienti (`https://app.audienti.com`). Both `audienti` and `tofu` run the same binary.

```sh
npm install -g @audienti/cli
audienti connect --name "My Agent"
audienti whoami
audienti wake --heartbeat --cmd 'your-agent "Claim queued Audienti work."'
```

Full agent onboarding guide: https://app.audienti.com/llms.txt
